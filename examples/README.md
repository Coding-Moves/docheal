# Drift examples

This folder is for small, readable cases that can guide DocHeal's first checks. It does not contain runnable tests yet.

Each example should show:

1. A short description of the original behavior.
2. A small before-and-after code or configuration snippet.
3. The documentation that became stale, or stayed correct.
4. What a useful warning would say, or why there should be no warning.

Keep examples self-contained and use made-up names and data. Avoid copying code or documentation from another project unless its license permits that reuse.
